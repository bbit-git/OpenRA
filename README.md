# RedOpsRTS

**RedOpsRTS** is a real-time strategy game powered by the **OpenRA engine**, adapted and optimized for modern platforms including Android.

This project is a fork of the open-source RTS engine **OpenRA** and focuses on delivering a classic base-building RTS experience with improved mobile usability and performance.

## Project

* Repository: [https://github.com/bbit-git/RedOpsRTS](https://github.com/bbit-git/RedOpsRTS)
* Engine: based on the OpenRA engine
* Platform focus: Android and modern systems

RedOpsRTS aims to bring classic RTS gameplay to modern devices while keeping compatibility with OpenRA mods and tooling where possible.

---

# Play

The engine supports classic Westwood-style RTS gameplay including mods inspired by:

* Command & Conquer: Tiberian Dawn
* Command & Conquer: Red Alert

These game assets are **not included** in this repository.

RedOpsRTS contains only the **open-source engine code**.
Game data must come from freeware releases or original game installations.

EA has **not endorsed and does not support this project**.

---

# Features

* Classic real-time strategy gameplay
